i2r.link의 보드 화면과 같은 역할입니다. 스위치를 누르면 MQTT로 so 명령을 보내고, 보드가 보낸 상태로 화면이 바뀝니다. 같은 서버, 같은 그룹이면 실제 보드도 여기 나타납니다.

번호: 사람이 보는 이름은 1부터, JSON은 0부터. 스위치 1 = OUT1 = "n":0 = "out"[0] = 코드 plc.output(1)

실제 보드와 같이 쓰려면 보드와 같은 서버, 같은 그룹이어야 합니다. 보드 그룹은 시리얼 모니터에 나옵니다 (따로 정하지 않았으면 MAC에서 :를 뺀 소문자).
가상 보드의 입출력, 규칙, 시간표는 그대로 옮겨 갑니다. 아이디·비밀번호가 있는 서버는 화면에서 바꿀 수 없으니 start-sim.bat --server 주소 --user 아이디로 다시 켜세요.

🔌 USB로 실제 보드 연결

보드를 USB로 연결하고, Arduino 시리얼 모니터와 i2r.link 웹은 닫아 두세요. Chrome, Edge에서 됩니다. 포트는 처음 한 번만 고르면 됩니다. 보드가 다시 시작할 때 출력은 모두 꺼집니다.

1. 보드와 연결 정보

가상보드 프로그램 다운로드: I2R_IoT 02_SimCheck를 쓰고(1분쯤), 이어서 위 정보를 보드에 넣습니다. 보드에 있던 프로그램(예전 i2r.link 펌웨어 포함)은 지워집니다. SSID를 비우면 보드에 있던 Wi-Fi 설정을 그대로 씁니다.
프로그램 다운로드 없이 정보만 입력: 가상보드 프로그램이 이미 있는 보드에 Wi-Fi, 서버만 넣습니다.
비밀번호는 USB로 보드에만 보냅니다. 시뮬레이터나 인터넷으로 보내지 않고, 이 화면에도 남기지 않습니다. Broker에는 지금 시뮬레이터 서버가 들어 있습니다 (시뮬레이터와 같아야 화면에 나타납니다).
